Welcome to Kenilworthford.com, a community resource designed to provide a quick, real-time indicator of whether the Kenilworth Ford is flooded.

The ford is located where Finham Brook crosses Castle Road (B4103).

How It Works & Data Limitations

This site automatically fetches river level data using the Environment Agency’s real-time data API. However, please be aware of the following technical limitations:

  • Location Variance: The data is pulled from the nearest monitoring station, which is located downstream from the ford.
  • Depth Variance: Any water depths displayed on this site reflect the levels at the monitoring station, not the exact depth at the ford itself. Localised conditions and rapid weather changes can cause conditions at the ford to differ from the automated readings.

Official, up-to-the-minute river levels can also be viewed directly on the Government flood warning information site.

This uses Environment Agency flood and river level data from the real-time data API (Beta).
