Flood information is for the "Kenilworth ford" which is where Finham Brook crosses Castle Road (B4103).

This site only provides guidance based on observations correlated to the level of the brook at the nearest monitoring station, located down stream from the ford. Use your own judgement before travelling through the ford and if you are unsure use an alternative route. This site accepts no responsibility for anyone travelling through the ford.

Recent levels are available on the Government flood warning information site.

This uses Environment Agency flood and river level data from the real-time data API (Beta)
